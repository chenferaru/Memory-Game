# Memory Game

A console-based Memory Game developed in C#, featuring both Player vs. Player and Player vs. Computer modes with adjustable AI difficulty levels.

## Features

- **Game Modes**:
  - Player vs. Player
  - Player vs. Computer with AI opponents of varying difficulty

- **AI-Powered Opponent**:
  - The computer player uses memory and logic to challenge the user
  - Multiple difficulty settings to adjust the challenge level

- **Modular Design**:
  - Separation of game logic and user interface for better maintainability

## Technologies Used

- C#
- .NET Framework

## Getting Started

### Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) installed on your machine

### Running the Game

1. Clone the repository:
   ```bash
   git clone https://github.com/chenferaru/Memory-Game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Memory-Game
   ```
3. Build and run the application using your preferred IDE or the command line.

## Project Structure

- `Engine/`: Contains the core game logic and AI implementation
- `UI/`: Handles user interaction and display in the console
